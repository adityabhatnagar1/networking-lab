# Networking Lab

Twenty hands-on computer networking experiments, documented deadly step by step.

![Networking Lab](assets/ishowspeed.gif)

</div>

## About

This repository collects 20 networking laboratory experiments as Markdown documents. Each experiment lives in its own numbered directory and covers one topic, from cabling and addressing to switch and router configuration, routing, access control lists and NAT.

It is intended for students working through a computer networks course, instructors looking for a lab sequence, and anyone preparing for entry level networking certifications who wants structured practice.

## Getting started

1. Clone the repository or download it as a ZIP.
2. Open the experiment you want. Directories are numbered `e01` to `e20` and sort in lab order.
3. Read the document from the top. Each one opens with its experiment heading and an aim.
4. Follow the steps in order, then compare your results with the expected output described in the document.

Many experiments use Cisco IOS commands, so [Cisco Packet Tracer](https://www.netacad.com/cisco-packet-tracer) is a convenient way to practise them without physical hardware. Packet Tracer project files are not included in this repository. You will need to build the topologies yourself from the instructions.
